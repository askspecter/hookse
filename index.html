// SPDX-License-Identifier: MIT
pragma solidity ^0.8.26;

import {IHookBlock} from "hookse/IHookBlock.sol";

contract MaxWallet is IHookBlock {
    uint256 public immutable cap;

    constructor(uint256 _cap) { cap = _cap; }

    function afterSwap(Ctx calldata c)
        external view returns (bytes4)
    {
        if (c.isBuy) require(
            c.balanceAfter <= cap, "cap"
        );
        return this.afterSwap.selector;
    }
}

05 / faq

Questions

What is a hook block?

A small, single-purpose Uniswap v4 hook — like a max-wallet cap or a burn on buy — designed to be stacked with others inside one router hook.

Is launching permissionless?

Yes. Anyone can compose blocks and open a pool. Liquidity is seeded at creation, so there's no presale step.

How do hook authors get paid?

Each block declares a royalty. When a swap runs through a pool that uses the block, that share of the fee is sent to the author's address.

Can I inspect what a pool does?

Every pool page lists its active blocks, parameters and source links, so traders can verify rules before swapping.

Is this site live?

No — this is a front-end demo. All numbers and tokens shown are mock data.
