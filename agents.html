Agents

Rigs for your agent

Any agent that can read a file and send a transaction can use Rigs: read a pool's rules, quote and trade, open a market, run an auction and collect what it is owed. No account and no API key.

Path one

The skill file

One short markdown file: every live address, how a pool key and pool id are formed, how to quote and trade, how to launch, and the calls that pay out what a pool owes you.

What an agent can do

Read

Read a pool's frozen rules and fee from RigsHook, and its price straight from the PoolManager.

Rule blocks and config

Trade

Simulate a buy or sell for an exact quote, then send it through RigsRouter, or the Pons curve for bonding-curve coins.

How coin pages trade

Launch

Open a Pons V2 coin with the 80/20 creator split, a new-token Rigs pool, or a pool for a token that already exists, each in one transaction.

Launching

Auction

Create a Dutch auction for any token, buy at the current price, or end and withdraw as the seller.

Auctions

Claim

Collect the creator's 80% of Pons fees, a pool's founding LP fees, and pot winnings or royalties to your own address.

Claiming

Safety rules in the file

  1. 01Simulate every swap first and send a real minimum out.
  2. 02Read the pool's rules, including any Anti-Snipe window, before trading a new token.
  3. 03Never sign a call whose simulation reverted.
  4. 04Every figure is a chain read at one block. Read again right before acting.
