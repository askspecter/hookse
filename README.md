# Hookse

A static front-end demo of a launchpad and marketplace for composable Uniswap v4 hooks.

- **Launch**: pick hook blocks and see the resulting fees, permissions and hook-address bits update live
- **Marketplace**: filterable list of hook blocks
- **Tokens**: searchable table of mock launches
- **Build / FAQ**: guide for hook authors

All data is mock data. Nothing is deployed on-chain.

## Run

No build step. Open `index.html` directly, or serve the folder:

```sh
python3 -m http.server 8000
```
